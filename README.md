# ДЗ 1 

## Описание

В работе реализованы основные компоненты механизма внимания трансформера и исправлены ошибки в предоставленной модели.

## Файлы проекта

- `dz1-attention.ipynb` — реализация четырёх функций и проверка корректности.
- `dz1-bughunt.ipynb` — исправление трёх ошибок, обучение модели и генерация текста.

## Окружение

Ноутбуки проверены в Google Colab с выбранным аппаратным ускорителем NVIDIA T4.

- Среда: Google Colab
- Ускоритель: NVIDIA T4
- PyTorch: 2.11.0+cu130
- Seed персонального варианта: 42
- Seed обучения: 0

## Как воспроизвести

1. Открыть https://colab.research.google.com/.
2. Загрузить `dz1-attention.ipynb` через «Файл → Загрузить блокнот».
3. В меню «Среда выполнения → Сменить среду выполнения» выбрать аппаратный ускоритель T4 GPU.
4. Нажать «Среда выполнения → Выполнить все».
5. Убедиться, что все 17 тестов успешно пройдены.
6. Аналогично загрузить `dz1-bughunt.ipynb`.
7. Проверить персональный seed `42` и seed обучения `0`.
8. Выполнить все ячейки последовательно.
9. Убедиться, что все 17 тестов пройдены.
10. Проверить график функции потерь и пример сгенерированного текста.

Для локального запуска можно использовать VS Code с расширениями Python и Jupyter и установленными зависимостями PyTorch, NumPy и Matplotlib.

## Результаты

Оба ноутбука успешно прошли по 17 проверок.

Во втором ноутбуке исправлены три ошибки:

1. Неверная начальная позиция в синусоидальном позиционном кодировании.
2. Неправильная ось нормализации в LayerNorm.
3. Неправильная ось softmax в механизме внимания.

Потери при обучении второго ноутбука уменьшились с 3.1844 на шаге 0 до 0.0411 на шаге 500.

После исправления ошибок модель генерирует повторяющиеся фрагменты обучающей последовательности.

График потерь и пример генерации сохранены в `dz1-bughunt.ipynb`.

После исправления ошибок тесты прошли успешно, потери при обучении уменьшились. Модель смогла воспроизвести фрагменты обучающего текста.
